# Powder Buoy

A study, not a product: does a Pacific Ocean buoy (NOAA 51101, the "Powder Buoy")
tell us anything useful about Utah snow that established climate signals don't
already tell us?

Full specification, rules, and current state live in [`SPEC.md`](SPEC.md) and
[`STATUS.md`](STATUS.md). Open questions and findings are logged in
[`DECISIONS.md`](DECISIONS.md). Read those before reading any code.
